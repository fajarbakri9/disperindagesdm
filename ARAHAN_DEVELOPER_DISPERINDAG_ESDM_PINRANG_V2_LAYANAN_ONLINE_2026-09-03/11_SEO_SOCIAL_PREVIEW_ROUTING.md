```text

```

- dashboard pemohon/admin harus noindex dan auth protected.

## 4. PROJECT B DOMAIN

Jika Project B menggunakan hostname Firebase:
- website utama tetap link ke route branded;
- bila custom domain/subdomain tersedia, gunakan satu identitas resmi.

Contoh konseptual:
```text
layanan.disperindagesdm.pinrangkab.go.id
```

Jangan mengubah domain resmi tanpa koordinasi pengelola domain Pemkab.
